# ToolVerse Fine-Tuned Models Directory

This directory stores trained LoRA adapter weights, fine-tuned checkpoints, and exported GGUF model binaries.

## Directories

- `regex-lora/`: LoRA adapter weights for Qwen2.5-Coder-7B fine-tuned on Regex dataset.
- `regex-gguf/`: Quantized GGUF model files ready for Ollama and vLLM local serving.
