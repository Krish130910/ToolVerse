# Do Not Use Sparkles Icon Rule

- **Do NOT use the `Sparkles` / `Sparkle` icon** (from `lucide-react`, SVGs, or any icon set) in UI designs, headers, cards, buttons, or badges.
- Use alternative icons like `Zap`, `Wrench`, `ShieldCheck`, `Cpu`, `Terminal`, or `Code2` depending on context.
- Applies to all UI components, templates, and future features across all projects.
